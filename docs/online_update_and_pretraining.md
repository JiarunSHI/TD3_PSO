# 持续在线 TD3-PSO：本次修改与预训练设计

> 历史说明：本文描述此前的 23 维在线方案。当前 9 维状态、相邻带符号奖励和多回合训练方法见 [training_100_episodes.md](training_100_episodes.md)。

## 任务语义

TD3 持续在线调整每个粒子的 w、c1、c2。`--iters` 仅决定实验观察到哪里，
不表示优化任务终止。因此经验保持 `(s,a,r,s_next)`，末步仍用 `r + gamma * Q_target`
进行自举，不添加虚构的终止标志，也不把实验末尾与另一次初始化后的状态相连。

空间边界与时间截断不同：地图位置边界、PSO 速度限幅和动作界限继续保留。
LDIW 对照算法自身的线性调度仍使用实验轮数；TD3 观察和探索不再依赖实验轮数。

## 初始化

每次生成候选路径：起终点直线 + 2.5 倍标准化累计二维高斯增量。
标准差在单条路径所有中间点的两个坐标上计算，不减均值。
候选路径任何坐标不在 `[MAP_MIN, MAP_MAX]` 内就整条丢弃，继续生成，
直到收齐 `n_particles` 条（默认 150）。不裁剪候选，不复制补齐，不排除碰撞候选。
起终点非法时立即报错；极端配置超过最大尝试次数也明确报错，避免无限循环。
`Particle` 和 `init_population` 共用相同规则。

## 23 维状态

前 9 维保留旧观察的适应度差距、相对改善、停滞、到 gbest 的距离、碰撞、
多样性、全局停滞、gbest 碰撞状态；删除 `progress=t/T`。

新增的特征按下列顺序排列：

| 名称 | 定义 |
|---|---|
| dist_pbest | 可移动点到对应 pbest 点的平均距离 / 地图边长 |
| pbest_collide | pbest 是否碰撞 |
| speed_rms | 当前速度分量的 RMS / v_max |
| speed_delta | 当前归一化速度 RMS 减去上一步的值 |
| velocity_change | 当前与上一步速度差的分量 RMS / (2 v_max) |
| velocity_turn_cos | 展平后当前速度与上一步速度的余弦 |
| velocity_pbest_cos | 当前速度与 pbest-pos 的余弦 |
| velocity_gbest_cos | 当前速度与 gbest-pos 的余弦 |
| attractor_cos | pbest-pos 与 gbest-pos 的余弦 |
| velocity_mean_x/y | 可移动点速度在 x/y 上的有符号均值 / v_max |
| clearance | 全路径线段到障碍物最小有符号净空 / 地图边长 |
| penetration | log(1 + 平均线段穿透代价) |
| best_collision_cost | log(1 + 该粒子历史最低碰撞代价) |

速度和吸引方向统计不包含固定端点。零向量的余弦约定为 0；速度大小和距离特征
可区分零向量与一般的正交情况。两点路径无可移动点，其速度特征自然为 0。
速度取 PSO 公式中实际保留的速度记忆，并非边界裁剪后的位移。

这些统计增强对惯性项、个体吸引和全局吸引作用的可观测性，但仍是压缩观察，
没有完整障碍布局、粒子几何和其他粒子的动作，不能声称严格满足马尔可夫性质。

## 奖励

令 P_old/P_new 为动作前后的 pbest 适应度，G_old 为动作前的 gbest 适应度，
F_new 为本次候选路径适应度。

对路径每条线段计算与最近障碍边界的有符号距离 d_j，定义：

```
penetration = sum_j(expm1(max(-d_j, 0)))
D = penetration / (路径点数 - 1) + 0.1 * collide
B_new = min(B_old, D)
```

B 是每个粒子独立维护的历史最低碰撞代价，初始化为初始路径的 D。
相切仍由碰撞检测判为碰撞，因此额外的 0.1 指示项保证只有无碰撞时 D 才为 0。
该纪录独立于适应度 pbest：即使绕行增加长度、总适应度尚未改善，穿透变浅也能获奖。
当前 D 与历史 B 不是同一概念，观察中分别提供了当前穿透/碰撞以及历史 B。

默认奖励为：

```
r_pbest = 10 * max(log(P_old / P_new), 0)
r_global = 5 * max(log(G_old / F_new), 0)
r_collision = 2 * max(log((0.05 + B_old) / (0.05 + B_new)), 0)
r_first_feasible = 1 if B_old > 0 and B_new == 0 else 0
r = r_pbest + r_global + r_collision + r_first_feasible
```

没有正向奖励硬上限。pbest 改善 10% 和 50% 的对应奖励约为 1.054 和 6.931，
不会再同时截成 1。`max(...,0)` 只去掉未改善情形，不截断正向幅度。
奖励系数及偏移量在 config.py 中集中设置。

碰撞过程只有创造新的穿透纪录才奖励：不断变浅可连续获奖；退回旧深度再恢复
不会重复获奖。首次无碰撞额外奖励只领取一次。已经找到过无碰撞路径后，
碰撞过程奖励归零，后续由适应度和全局改善驱动；不会无限奖励无意义的净空增大。
这仍可能在长期停滞时产生稀疏奖励，属于选择的探索/信用分配取舍。

Adam 并不能保证极端奖励下稳定。本次通过对数和正偏移控制尺度，同时保留改善幅度，
没有因为取消硬上限而修改或撤销 PSO 的物理/参数边界。

## 与实验长度无关的探索

前 warmup_iters 轮仍使用均匀随机动作。之后：

```
sigma = sigma_end + (sigma_start - sigma_end)
                     * exp(-max(t - warmup_iters, 0) / expl_decay_iters)
```

`--expl-decay-iters` 默认 250，是噪声时间常数，不是任务终点；250 轮后仍可持续运行。
相同种子与配置下，改变 `--iters` 不改变 TD3 运行的共同前缀。

旧 10 维模型不能直接载入 23 维网络。加载时会给出明确的维度不兼容错误；
已有模型和结果不覆盖。维度相同也不自动表示语义兼容，后续预训练应保存状态名与版本。

## 离线预训练设计（方案，本次不实现预训练器）

### 推荐起点：部署前的多地图仿真预训练

如果可以反复调用 PSO 仿真，先在部署前训练一个共享 TD3，成本和实现复杂度较低。
这属于部署前预训练，训练过程中仍可与仿真交互，并不是严格的固定数据集离线 RL。

1. 固定并保存开发、验证、最终测试的地图集合；按地图划分，而不是随机拆分同一轨迹。
   先修复已发现的随机流重合和地图起终点覆盖问题，统一验证地图有效性。
2. 在多个开发地图、种群种子、PSO 种子上创建新种群；每条轨迹重新建立 pbest、gbest、
   速度历史和碰撞纪录。网络、目标网络和训练回放池跨轨迹保留。
3. 预热和探索采用跨轨迹的训练交互计数，不能每换地图又强制从第 0 步重来。
   混合短/长采样片段，避免数据只集中于初期或已完全停滞的种群。
4. 通过共享 replay 学习 23 维状态到 3 维归一化参数动作的映射。
   训练轮数截断继续 bootstrap；不要把重置地图后的状态接到上一条轨迹末尾。
5. 在验证地图上分别测冻结策略、预训练后在线微调的效果，以路径成功率、成功后质量、
   首次可行时间和在线训练开销选模型，不能只看训练奖励或 Critic loss。
6. 部署时载入网络，使用少量探索；短预热甚至 warmup=0 可作为验证候选，
   回放未满 batch_size 时只收集不更新。是否保留预训练 replay 及混合比例由验证决定。

### 只有历史日志时：固定数据集离线训练

现有 10 维数据不包含速度/碰撞纪录，不能靠补零转换为本次数据。
应重新采集，或从足够完整的原始种群轨迹重新计算。

建议混合固定参数、LDIW、随机参数和已有策略的轨迹，保存：
`map_id, trajectory_id, particle_id, s, raw_action, reward_components, s_next`，
以及状态名、奖励系数、所有种子、代码版本；需要重算时还应保存位置、速度、pbest、
gbest、碰撞几何和历史纪录。动作必须是实际执行的加噪归一化动作，不能用无噪 Actor 输出替代。

直接在固定数据集上反复调用普通 TD3，可能让 Actor 追逐数据覆盖之外的错误 Q 值。
可从 TD3+BC 开始，对 Actor 增加行为克隆约束：

```
L_actor = -lambda * mean(Q1(s, actor(s)))
          + mean(||actor(s) - a_data||^2)
```

lambda、数据混合和状态标准化只在开发/验证集合确定。不要把所有随机动作都当成专家动作。
按地图/轨迹均衡采样，并保留未改善、失败与碰撞状态，避免只训练成功样本。
切换到在线 TD3 后可逐渐减弱 BC 约束，并逐渐提高新经验的采样比例；这是待验证方案。

参考：Fujimoto & Gu, A Minimalist Approach to Offline Reinforcement Learning (TD3+BC),
https://arxiv.org/abs/2106.06860 。离线分布外价值误差背景：
Fujimoto et al., Off-Policy Deep Reinforcement Learning without Exploration,
https://arxiv.org/abs/1812.02900 。

### 预训练必须有的对照与保存内容

对照：从零在线 TD3、预训练冻结策略、预训练后在线 TD3，以及开发集选定的强固定参数 PSO。
所有方法用相同测试地图/种群/PSO 随机条件；分别报告离线总成本和每次在线成本。
最终测试集合不能参与奖励、状态、网络或模型选择。

可迁移的模型至少保存网络权重、完整状态顺序、动作映射、奖励版本和归一化参数。
若要精确恢复训练，还需目标网络、Adam 状态、更新计数、RNG 状态和 replay；
当前 save_model/load_model 仅用于权重热启动，不是精确续训快照。

## 验证记录

- 8 项新增回归测试通过：拒绝采样、越界/耗尽报错、速度方向趋势、无硬上限奖励、
  碰撞纪录与防重复奖励、持续任务自举、截断无关的运行前缀、模型维度兼容。
- 原有 4 项一致性测试通过。
- 地图 42、种子 0/1 各运行 250 轮、150 粒子：23 维状态均有限，
  各收集 37500 条经验、984 次 Critic 更新，最终均无碰撞。
  best_f 分别约 10.29693、10.50791；最大单步奖励约 26.83、26.19。
  Actor 饱和率仍约 100% 和 84.2%，因此不宣称本次修改已经解决饱和或提高整体性能。
- 四种方法的对比脚本冒烟运行通过，相关性输出适配新状态。
  本机用户级 NumPy 与系统 SciPy 有版本冲突，对比脚本使用 `python -s -B` 避开用户级包。
  算法测试使用常规 Python；未修改系统依赖。
- 已知的随机流重合、地图起终点保护不属于本次四项修改，后续正式统计前仍需处理。
